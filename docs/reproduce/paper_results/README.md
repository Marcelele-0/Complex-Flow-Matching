# Archived evaluations behind the paper's tables

Every number in the paper's U-Net tables is read from a file in this directory, so
the tables can be printed, checked and turned into LaTeX without retraining.
Evaluating a fixed checkpoint is exactly reproducible; retraining is seeded but GPU
kernels are not bitwise deterministic, so a retrained model matches within the seed
spread, not to the digit.

## Files

| file | contents | protocol | seeds | hardware |
| --- | --- | --- | --- | --- |
| `unet_eval_metrics.json` | arXiv v1 Tables 2-3 | L1, cylinder phase weighted by `A_1 / mean(A_1)` | 0, 1 | RTX 4070 Ti SUPER |
| `unet_eval_metrics_l2u.json` | v2 Tables 2-3 (matched loss) | L2 in both geometries, phase unweighted | 0-4 | H100 |
| `unet_eval_metrics_l1u_cylindrical.json` | appendix table, cylinder | L1, phase unweighted | 0-4 | H100 |
| `unet_eval_metrics_l1w_cartesian.json` | appendix table, Cartesian | L1 (the Cartesian loss has no phase weighting) | 0-4 | H100 |
| `table5_fastmri64_metrics.json` | main-text Table 5, knee MRI 64x64 | L2, phase unweighted, `dataset.kspace_crop=64` | 0-4 | H100 |
| `table5_fastmri_metrics.json` | Appendix D, knee MRI 320x320 | L2, phase unweighted, no crop | 0-4 | H100 |
| `table6_audio_metrics.json` | main-text Table 2, speech block | L2, phase unweighted, LibriSpeech STFT, 40 epochs | 0-4 | H100 |
| `latex/*.tex` | the tables as the paper includes them | generated by `scripts/paper/latex_tables.py` | | |

The two knee archives do not share the synthetic grid's `(side, geometry, coupling,
seed)` shape, which is why `tests/test_paper_results.py` gives them their own tests
rather than a fourth `ARCHIVES` entry. `table5_fastmri64_metrics.json` holds **two
sweeps of the same 25 checkpoints** -- a five-point NFE list and an eleven-point dense
one, the latter being where the caption's k* is read off -- plus two diffusion arms
scored from a single checkpoint under different sampling regimes, for 50 entries in
all. `table5_fastmri_metrics.json` holds 20, not the 30 the config's `expected:` block
predicts: the diffusion baseline was run at 64x64 only, and that absence is named in
the tests rather than tolerated silently.

Neither has a LaTeX renderer yet. `latex_tables.py` carries the `TABLE5C64_*` grid
definition that `export_table5c64.py` reads, but rendering was deliberately deferred,
so the main text's knee table is still hand-written LaTeX.

The three v2 archives cover the full grid: field sides 16, 32 and 64 x coupling
{independent, joint OT} x seeds 0-4, for the geometries named in the file (both in
`_l2u`). The v1 archive covers the v1 grid (both geometries at 64x64, Cartesian OT
and both cylindrical couplings at 16x16 and 32x32, seeds 0 and 1).

## Protocol

All v2 runs use the experiment configs in `conf/experiment/`:

| config | loss | archive |
| --- | --- | --- |
| `paper_unet` | L2, phase unweighted | `_l2u` |
| `paper_unet_l1` | L1, phase unweighted | `_l1u_cylindrical` |
| `paper_unet_v1loss` | L1, phase amplitude-weighted (the v1 objective) | `_l1w_cartesian` |

Shared settings: `cylinder_toy_field` (copula target, rho 0.5, correlation length
4, 8192 fields, each normalised by its own peak modulus), `c_unet`, 40 epochs, batch
64, no gradient clipping, the white uniform prior, noise bridge. Per run only the
geometry (`manifold=`), the coupling (`training.coupling=`), the field size
(`dataset.crop_size=`) and the seed (`training.seed=`) change. Evaluation: 64
generated fields against 64 reference fields, Heun with k = 1, 2, 4, 8, 100 steps
(2k - 1 function evaluations), `evaluate.seed` equal to the training seed.

## Entry format

Keys are the unprefixed run names written by the table scripts:
`un_{geometry}_{coupling}_scnull_s{seed}_eval` at 64x64 and
`unsz_{geometry}_{coupling}_{side}_s{seed}_eval` at 16x16 and 32x32. Each value is
the evaluation's `metrics.json` (a `sweep` row per step count with
`sliced_w2_complex`, `w2_amplitude`, `w2_phase_circular`, `dependence_gap`,
angular-velocity and spatial statistics) plus, in the v2 archives, a `provenance`
record:

- `train_run`, `train_overrides` -- the Hydra run directory and the exact overrides
  the checkpoint was trained with;
- `evaluate_run`, `evaluate_overrides` -- the same for the evaluation.

The v2 runs were launched with explicit overrides equivalent to the experiment
configs; `tests/test_paper_results.py` composes both for every entry and asserts
that they give the same configuration.

## Hardware and software of the v2 runs

Every v2 run trained and was evaluated on a single NVIDIA H100 (80 GB), with torch
2.11.0 (CUDA 13.0) from `uv.lock` and the `src/` of this repository, one run per
GPU. Any recent CUDA GPU reproduces them; on an RTX 4070 Ti SUPER a 64x64 run takes
about 20 minutes.

## Reproducing and checking

```bash
# check the archives: full grid, metadata, and recorded config == documented experiment
uv run pytest tests/test_paper_results.py

# print Tables 2-3 and the per-seed checks from an archive
uv run python scripts/paper/paper_tables.py --archive \
    --archive-file docs/reproduce/paper_results/unet_eval_metrics_l2u.json --seeds 0 1 2 3 4

# both loss protocols with bootstrap intervals and exact Mann-Whitney p
uv run python scripts/paper/loss_protocols.py --archive [--metric w2_phase_circular]

# regenerate the LaTeX the paper includes
uv run python scripts/paper/latex_tables.py

# retrain a result from its config in conf/experiment/ (resumes if interrupted)
uv run python scripts/paper/reproduce.py tableA_loss_protocols

# or a quick check with one seed at 16x16
uv run python scripts/paper/reproduce.py tableA_loss_protocols \
    --seeds 0 --sides 16 --tag quick_
```

After retraining, export an archive with `paper_tables.py --export --prefix PREFIX
--seeds 0 1 2 3 4 --archive-file FILE` (add `--partial` for a one-geometry archive);
the export attaches the provenance record from `outputs/train` and `outputs/evaluate`.
