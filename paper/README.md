# The paper

`ICLR Main/` is the manuscript, and the only Overleaf project tracked here.

Overleaf remains the editing surface; this copy exists so the manuscript is
versioned beside the code that produces its numbers, and so a reader of the
repository can see the paper without an Overleaf account. The two can drift, so
when they disagree Overleaf is newer unless a commit here says otherwise.

The Overleaf project also holds `NIPS Main`, `NIPS GDDL workshop` and
`NIPS SD workshop`. They are superseded drafts, kept on Overleaf and removed
from this repository: the venue decision settled on one paper rather than three,
and the workshop versions are not on the path to it. They remain in this
repository's history.

`overleaf_cache/` is the MCP server's working clone of the same project and is
ignored by git. Do not edit the manuscript there expecting it to reach this copy.
